==============================================================================
Figure 3 - Analysis Code
==============================================================================
This document contains the analysis code for Figure 3 and its source-data workbook
(Figure3_source_data_EN.xlsx). The code is organised by panel. Every section states
the worksheet that holds the underlying values, the statistical method used, and the
R code that reproduces the panel from that worksheet.

Analysis outline
  RNA sequencing      FAD_SH versus FAD_SH_NC, three mice per group; DESeq2,
                      then GO and KEGG over-representation analysis and GSEA.
  Metabolomics        untargeted, negative ion mode; five NC and five shOxr1 samples;
                      log2(x + 1) transformation, Welch t-test, Benjamini-Hochberg.
  Targeted fatty acids three versus three samples; Welch t-test on group means.
  Lipidomics          positive and negative ion modes; three versus three samples.

The workbook is self-contained: the code reads values from the worksheets, so no
other input file is required.

==============================================================================
0  Overview
==============================================================================

Data sheet : all worksheets

Method     : Figure 3 reports the effect of astrocytic Oxr1 knockdown on the lipid landscape. Four data sets are combined: (i) hippocampal RNA sequencing of FAD_SH versus FAD_SH_NC mice (three animals per group) analysed by GO, KEGG and GSEA; (ii) untargeted metabolomics in negative ion mode (five NC and five shOxr1 samples); (iii) a targeted fatty acid panel (three versus three); (iv) lipidomics in positive and negative ion modes (three versus three).

Packages   : R 4.2 or newer; ggplot2, dplyr, tidyr, readxl, ComplexHeatmap, circlize, aPEAR, clusterProfiler, fgsea

==============================================================================
2  Panel b - GO enrichment map
==============================================================================

Data sheet : F3b_GO_network and F3b_GO_BP_input

Method     : Enrichment map of the significant GO biological-process terms. Pathway similarity is the Jaccard index of shared genes; terms are clustered hierarchically (complete linkage, k = 10, clusters with fewer than three terms merged) and the network is laid out by aPEAR with an inner cutoff of 0.4 and an outer cutoff of 0.6. Node size is the gene count, node colour the -log10 adjusted p value.


------------------------------------------------------------------------------
R code
------------------------------------------------------------------------------

library(aPEAR)
library(igraph)

go <- sh("F3b_GO_BP_input")
cl <- sh("F3b_GO_network")

sig <- go %>%
  filter(p.adjust < 0.05) %>%
  mutate(geneID = gsub("[,; \t]+", "/", geneID))

sim <- pathwaySimilarity(as.data.frame(sig), geneCol = "geneID", method = "jaccard")
hc  <- hclust(as.dist(1 - sim), method = "complete")

clusters_raw <- cutree(hc, k = 10)
keep         <- names(table(clusters_raw))[table(clusters_raw) >= 3]
clusters     <- clusters_raw[clusters_raw %in% keep]

graph <- aPEAR:::enrichmentNetwork.connect(sim = sim[names(clusters), names(clusters)],
                                           clusters = clusters,
                                           innerCutoff = 0.4, outerCutoff = 0.6)
coords <- graph$coordinates
edges  <- graph$edges

coords <- coords %>%
  left_join(sig %>% select(Description, Count, p.adjust) %>%
              mutate(logP = -log10(p.adjust)),
            by = c("ID" = "Description"))

# Node coordinates depend on the force-directed layout of aPEAR; the cluster
# membership and the per-term statistics are given in worksheet F3b_GO_network.

4  Panel d - GSEA of all genes
==============================================================================

Data sheet : F3d_GSEA_all_genes

Method     : Gene set enrichment analysis of the complete ranked gene list, run separately for GO biological process and KEGG. d <- sh("F3d_GSEA_all_genes") %>%

==============================================================================
5  Panel e - lipid metabolism categories
==============================================================================

Data sheet : F3e_LipidCat_summary and F3e_LipidCat_pathways

Method     : Sixty-six significant lipid-metabolism pathways were assigned to six functional categories. For each category the figure plots the negative mean normalised enrichment score against -log10 of the mean adjusted p value; symbol size is the number of pathways in the category.


------------------------------------------------------------------------------
R code
------------------------------------------------------------------------------

p <- sh("F3e_LipidCat_pathways")

s <- p %>%
  group_by(Category) %>%
  summarise(n = n(),
            mean_NES  = mean(NES),
            mean_padj = mean(p.adjust),
            .groups = "drop") %>%
  mutate(x = -log10(mean_padj), y = -mean_NES)

ggplot(s, aes(x = x, y = y)) +
  geom_point(aes(size = n, colour = x)) +
  scale_size_continuous(range = c(3, 9), name = "Number of pathways") +
  scale_colour_gradient(low = "#4575B4", high = "#D73027", name = "-log10(mean p.adjust)") +
  geom_text(aes(label = Category), vjust = -1.3, size = 3, check_overlap = TRUE) +
  scale_y_continuous(limits = c(1.7, 2.0)) +
  labs(x = "-log10(mean p.adjust)", y = "-Mean NES",
       title = "Lipid Metabolism Categories") +
  theme_minimal(base_size = 12)

6  Panel f - PCA of untargeted metabolomics (negative ion mode)

Data sheet : F3f_PCA_input_log2 and F3f_PCA_Neg_scores

Method     : Metabolite intensities were transformed as log2(x + 1) and centred; principal components were computed across the ten samples (five NC and five shOxr1). The score plot shows PC1 and PC2 with 95% confidence ellipses.


------------------------------------------------------------------------------
R code
------------------------------------------------------------------------------

m <- sh("F3f_PCA_input_log2")
X <- t(as.matrix(m[, -1]))
rownames(X) <- colnames(m)[-1]

pca <- prcomp(X, center = TRUE, scale. = FALSE)
sc  <- data.frame(pca$x[, 1:2],
                  Group = c(rep("NC", 5), rep("shOxr1", 5)))

ggplot(sc, aes(x = PC1, y = PC2, colour = Group)) +
  geom_point(size = 2.5) +
  stat_ellipse(level = 0.95, show.legend = FALSE) +
  labs(title = "PCA ( Neg. )") +
  theme_classic(base_size = 11)

round(100 * summary(pca)$importance[2, 1:2], 1)


==============================================================================
7  Panel g - differential metabolites, negative ion mode
==============================================================================

Data sheet : F3g_Volcano_Neg

Method     : For each metabolite, log2 fold change was computed from log2(x + 1) group means and a Welch t-test was applied to the log2 intensities; p values were adjusted by the Benjamini-Hochberg procedure. Thresholds for significance are |log2FC| > log2(1.5) = 0.585 and p < 0.05.


------------------------------------------------------------------------------
R code
------------------------------------------------------------------------------

d <- sh("F3g_Volcano_Neg") %>%
  mutate(Significant = factor(Significant,
                              levels = c("Down-regulated", "Not Significant", "Up-regulated")))

ggplot(d, aes(x = log2FC, y = `-log10(p_value)`, colour = Significant)) +
  geom_point(size = 2.2, alpha = 0.8) +
  geom_vline(xintercept = c(-0.585, 0.585), linetype = "dashed") +
  geom_hline(yintercept = -log10(0.05), linetype = "dashed") +
  scale_colour_manual(values = c("#2E86AB", "#B8B8B8", "#D62828")) +
  labs(x = "log2(Fold Change) [SH/NC]", y = "-log10(p-value)",
       title = "Differential Metabolites",
       subtitle = "Negative ion mode (n = 5 NC vs 5 SH samples)",
       caption = sprintf("Thresholds: |log2FC| > 0.58, p < 0.05\nSignificant metabolites: %d up, %d down",
                         sum(d$Significant == "Up-regulated"),
                         sum(d$Significant == "Down-regulated"))) +
  theme_classic(base_size = 11)
