==============================================================================
Single-cell panels of Figure 1, Figure S1 and Figure S2 - Analysis Code
==============================================================================
This document contains the analysis code for every panel of Figure 1, Figure S1 and Figure S2 that is
derived from single-cell data, together with the source-data workbook
Figure1_S1_S2_singlecell_source_data_EN.xlsx. The code is organised by panel: each section names the
worksheet that holds the underlying values, states the method, and gives the R code that reproduces the
panel from that worksheet.

Dataset
  Single-cell RNA sequencing of Abeta-treated neural cultures versus scrambled control.
  9,799 cells after quality control; clustering at resolution 0.1; four annotated cell types;
  reactive astrocytes re-clustered at resolution 0.3 into three subclusters.
  Processing: Seurat 5 (normalisation, variable features, PCA, UMAP, Louvain clustering,
  Wilcoxon rank-sum tests with Benjamini-Hochberg adjustment).

Additional data sources
  Figure S1h            SEA-AD human single-nucleus RNA sequencing (middle temporal gyrus and
                        dorsolateral prefrontal cortex); donor-level pseudobulk CPM.
  Figure S2j            Deep multilayer brain proteome of AD, AsymAD and control brains
                        (Bai et al.); log2 protein ratios.
  Figure S2h and S2i    MIST database of experimentally validated and inferred protein interactions.

The workbook is self-contained: the code reads values from the worksheets, so no other input file is
required.

==============================================================================
0  Overview
==============================================================================

Data sheet : all worksheets

Method     : The single-cell panels of Figure 1, Figure S1 and Figure S2 come from one dataset of Abeta-treated neural cultures profiled by droplet-based single-cell RNA sequencing. After quality control, 9,799 cells were retained from two conditions (Abeta 3 weeks and scrambled control), clustered at resolution 0.1 and annotated into four cell types: basal neurons, synaptic neurons, astrocytes and reactive astrocytes. Reactive astrocytes were re-clustered at resolution 0.3 into three subclusters. All values in the workbook were produced with Seurat 5.0 (log-normalisation, UMAP, Wilcoxon tests) and are reproduced by the code below.

Packages   : R 4.2 or newer; Seurat 5, ggplot2, dplyr, tidyr, readxl, ComplexHeatmap (optional)

==============================================================================
14  Figure S1h - OXR1 in reactive versus homeostatic astrocytes (human SEA-AD)
==============================================================================

Data sheet : S1h_OXR1_donors, S1h_OXR1_summary, S1h_threshold_sensitivity

Method     : Astrocytes from the SEA-AD single-nucleus RNA-sequencing dataset were classified within each donor by a marker-detection reactivity score (proportion of six reactive markers detected minus proportion of three homeostatic markers detected). The top and bottom deciles of each donor were compared by donor-level pseudobulk CPM with a two-sided paired Wilcoxon signed-rank test.


------------------------------------------------------------------------------
R code
------------------------------------------------------------------------------

d <- sh("S1h_OXR1_donors")
s <- sh("S1h_OXR1_summary")

# per-donor points with group means and standard errors
long <- d %>%
  select(region, donor, OXR1_CPM_reactive, OXR1_CPM_homeostatic) %>%
  pivot_longer(c(OXR1_CPM_reactive, OXR1_CPM_homeostatic),
               names_to = "state", values_to = "CPM") %>%
  mutate(state = recode(state,
                        OXR1_CPM_reactive    = "Reactive",
                        OXR1_CPM_homeostatic = "Homeostatic"))

agg <- long %>%
  group_by(region, state) %>%
  summarise(mean_CPM = mean(CPM), sem = sd(CPM) / sqrt(n()), .groups = "drop")

ggplot(agg, aes(x = state, y = mean_CPM, fill = state)) +
  geom_col(width = 0.6) +
  geom_errorbar(aes(ymin = mean_CPM, ymax = mean_CPM + sem), width = 0.15) +
  geom_point(data = long, aes(x = state, y = CPM),
             inherit.aes = FALSE, size = 0.6, alpha = 0.35) +
  facet_wrap(~ region, nrow = 1) +
  labs(x = NULL, y = "OXR1 (CPM)", title = "OXR1 homeostatic vs reactive") +
  theme_classic(base_size = 10)

# paired test per region (matches the p values in the summary sheet)
for (r in unique(d$region)) {
  x <- d$OXR1_CPM_reactive[d$region == r]
  y <- d$OXR1_CPM_homeostatic[d$region == r]
  cat(r, "n =", length(x), "paired Wilcoxon p =",
      format(wilcox.test(x, y, paired = TRUE)$p.value, digits = 4), "\n")
}

s   # group means, percentage change and p values used in the figure legend

17  Figure S2j - interacting protein levels across AD, AsymAD and control (BH-adjusted p values)
==============================================================================

Data sheet : S2j_protein_expression, S2j_group_means, S2j_group_z, S2j_pairwise_p

Method     : Protein abundance was taken from the deep multilayer brain proteome of Bai et al. For each protein the group-mean expression was z-scored across the three diagnostic groups and drawn as a heatmap. The three pairwise comparisons were tested with two-sided Wilcoxon rank-sum tests and adjusted by the Benjamini-Hochberg procedure within each comparison; the panel is annotated with the adjusted p values.


------------------------------------------------------------------------------
R code
------------------------------------------------------------------------------

d  <- sh("S2j_protein_expression")
gz <- sh("S2j_group_z")
pw <- sh("S2j_pairwise_p")

fmt <- function(p) ifelse(p < 0.001, formatC(p, format = "e", digits = 1),
                          formatC(p, format = "f", digits = 3))

ord <- c("ERC2", "TENM2", "ST13", "GSK3A", "GSK3B", "NCAM1", "MYO1C",
         "TENM1", "IQGAP1", "ADAM10", "DDHD2", "LIG4", "NTN1")
lev <- c("Control", "AsymAD", "AD",
         "AsymAD vs Control", "AD vs Control", "AD vs AsymAD")

gz$Column <- factor(as.character(gz$Group), levels = lev)
pw$Column <- factor(as.character(pw$Comparison), levels = lev)
gz$Protein <- factor(gz$Protein, levels = rev(ord))
pw$Protein <- factor(pw$Protein, levels = rev(ord))
pw$label <- fmt(pw$p_adj)

ggplot() +
  geom_tile(data = gz, aes(x = Column, y = Protein, fill = z),
            colour = "white", linewidth = 0.6, na.rm = TRUE) +
  geom_text(data = pw, aes(x = Column, y = Protein, label = label), size = 2.7) +
  scale_fill_gradient2(low = "#2e90ad", mid = "#fdfdfb", high = "#ee8c0f",
